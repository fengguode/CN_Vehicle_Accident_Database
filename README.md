# China ADAS Accident Public Database / 中国 ADAS 事故公开数据库

This repository contains the sanitized, static publication generated by the companion [`china-adas-accident-methods`](../china-adas-accident-methods) repository. It is suitable for public hosting (for example, GitHub Pages): open [`site/index.html`](site/index.html) for the rendered view or [`data/reports.json`](data/reports.json) for machine-readable records.

## Data contract

`data/reports.json` is an array of records. Each record has a stable `id` and `fingerprint`, provenance (`source_url`, `source_name`, `platform`), dates, automatic labels (`brand`, `cause`, `adas_mode`, `road_type`, `severity`, `province`, `city`), counts, `verification_status`, `relevance_score`, and `labels`. `data/metadata.json` records the schema version, generation time, count, and publication policy.

All records are leads unless `verification_status` is `human_verified`; inclusion does not establish that ADAS caused an incident. The public export excludes `raw_json`, SQLite files, logs, and other internal fields.

## Regenerate

From the methods repository run:

```powershell
npm run publish -- ..\china-adas-accident-database
# or
.\scripts\publish-public.ps1
```

Review the generated diff in this repository, then commit and publish it. Generation is deterministic for the database contents except for `generated_at` metadata and the generated date shown in the page.
