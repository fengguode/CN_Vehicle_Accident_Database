# China ADAS Accident Public Database / 中国 ADAS 事故公开数据库

This repository contains the sanitized, static publication generated by the companion [methods repository](https://github.com/fengguode/CN_Vehicle_Accident_Updater). It is suitable for public hosting (for example, GitHub Pages): open [`site/index.html`](site/index.html) for the rendered view or [`data/reports.json`](data/reports.json) for machine-readable records.

## Data contract

`data/reports.json` is an array of records. Each record has a stable `id` and `fingerprint`, provenance (`publisher_name` and `source_url` identify the resolved publisher when available; `source_name` and `discovery_url` retain discovery provenance), dates, automatic labels (`brand`, `cause`, `adas_mode`, `road_type`, `severity`, `province`, `city`), counts, `verification_status`, `relevance_score`, `labels`, and a clearly marked machine-generated `english_description`. `data/metadata.json` records the schema version, generation time, count, and publication policy.

All records are leads unless `verification_status` is `human_verified`; inclusion does not establish that ADAS caused an incident. The public export excludes `raw_json`, SQLite files, logs, and other internal fields.

## Regenerate

From the methods repository run:

```powershell
npm run publish -- ..\china-adas-accident-database
# or
.\scripts\publish-public.ps1
```

Review the generated diff in this repository, then commit and publish it. Generation is deterministic for the database contents except for `generated_at` metadata and the generated date shown in the page.

## Automated updates and hosting

The `Daily accident data update` workflow runs at 00:00 UTC (08:00 Asia/Shanghai), checks out the public methods repository, hydrates its local database from the current public JSON, collects enabled sources, republishes the sanitized JSON and HTML, and commits changes with the public repository's `GITHUB_TOKEN`. It is also manually runnable from the Actions tab.

The `Deploy public database site` workflow publishes `site/` to GitHub Pages on every push. In repository Settings → Pages, select **GitHub Actions** as the source if Pages has not been enabled yet.
